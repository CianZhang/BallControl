# 滚球控制系统（2017 年全国大学生电子设计竞赛 B 题）

滚球控制系统完整代码，基于OpenMV识别和STM32RCT6，代码全注释。有帮到你请点个小星星^_^

本项目以 OpenMV 识别小球位置，STM32F103RCT6 运行两轴串级 PID，并用两个舵机调节木板倾角。工程包含 OpenMV 脚本、Keil STM32 工程和赛题 PDF。

使用两个舵机控制木板的X轴和Y轴的倾斜，一定要注意中间支撑轴的稳定，结构好了PID就好调。 

使用串级PID,内环速度环，外环位置环。调节PID的时候，先调速度环，将速度环目标设置为0，kp,ki,kd都先给0，然后只调kd，只用kd能将小球停在木板上，就差不多可以了，之后再加位置环。 

注意木板的初始角度，就是舵机的初始角度，是让木板保持水平。

可以理解为当PID输出为0时，就是舵机的初始角度，此时木板应当是水平的，小球才能保持不动。

至于为什么在代码里面修正目标值，因为我的木板有点不平整，修正目标点可以做到进入目标区域。

如果可以，你可以在PID中加一个判断条件，作用于积分I，当实时坐标与目标坐标差很远时，不进行积分I；当接近目标点时，才加入积分I，这样可以把积分I值提高，使小球准确进入目标区域^_^

自己的想法：这一类题，小球由于重力，自身是有动力的，舵机做的只是控制方向，那么就先调D，PID中的D是通过预测来控制，通过预测小球的速度将小球停下来，风力摆与之类似。

## 项目结构

| 路径 | 作用 |
| --- | --- |
| `OpenMV/main.py` | 小球色块识别；通过 USART1 发送位置和相邻帧位移。 |
| `STM32RCT6/hardware/Servo.c` | 两个位置外环、两个“速度”内环的初始化与串级控制。 |
| `STM32RCT6/hardware/PID.c` | PID 计算、积分限幅（`±600`）。 |
| `STM32RCT6/hardware/UART3_OpenMV.c` | 接收 OpenMV 的位置 `points_x/y` 和位移 `dx/dy`。 |
| `STM32RCT6/hardware/ball_control.c` | 九宫格目标点及各赛题运动路线。 |

## 控制链路

```text
OpenMV 位置 (points_x, points_y)
        │
        ▼
位置 PID（外环） ──► 期望帧间位移
        │
        ▼
位移/速度 PID（内环）──► 舵机角度增量 ──► 木板倾角 ──► 小球
```

项目中 `dx`、`dy` 是相邻图像帧的位置差，并非除以采样周期后的标准速度；因此文档中称“位移/速度内环”。实际控制参数位于 [`Servo.c`](STM32RCT6/hardware/Servo.c)：

```c
PID_Init(&p_pid_x, 0.1, 0.0016, 0.08);
PID_Init(&p_pid_y, 0.1, 0.00255, 0.08);
PID_Init(&v_pid_x, 0, 0, 1.1);
PID_Init(&v_pid_y, 0, 0, 1.1);
```

## 使用前必做

1. 将 OpenMV 脚本烧录到相机，将 Keil 工程编译下载到 STM32。
2. 确认木板的中心支撑不晃动、舵机无明显虚位、相机和光源固定。机械问题会直接表现为 PID 难以整定。
3. 以 `Servo_move_by_degress(75, 55)` 为基准校准水平。PID 输出为零时，木板应尽可能水平；若不平，优先修改该基准角度，而不是靠积分硬拉回来。
4. 分别确认 X/Y 轴的正方向。若控制方向反了，调整 `servo_rotation_direction` 或 `servo_pitch_direction`，不要通过把 PID 参数调为负数来补偿。

## PID 调参

完整的参数含义、推荐顺序、现象对照和代码注意事项见 [PID 调参指南](PID调参指南.md)。核心原则是：**先让内环把球的运动可靠地刹住，再调外环让球快速到达目标；积分最后才加入。**

## 已知实现特性

- PID 使用离散形式 `integral += error`、`derivative = error - previous_error`，未显式包含采样周期 `dt`；更换帧率或控制循环频率后，原参数不能直接沿用。
- OpenMV 仅在识别到色块时更新数据。开始调参前应确保图像稳定、连续识别，且首次位移样本不会被当作真实速度。
- 当前 `UART3_OpenMV.c` 的接收缓存定义为 10 字节，而 OpenMV 在包头后发送 11 字节；接收状态机也会在首帧后等待额外包尾。应先修正并验证持续收帧，再依据 `dx/dy` 调 PID。
- 舵机输出会被限制在 10°–150°。频繁撞到限位时，应先减小增益或缩短目标跳变，而不是继续提高积分。
